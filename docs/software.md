# Useful Bioinformatics Software

## [PlaceBot - Multi-Vendor AI Locality Processor](https://github.com/JackDanHollister/PlaceBot)

PlaceBot is a lightweight tool designed to convert verbatim locality descriptions, such as those found on natural history specimen labels, into standardised geographic coordinates (latitude and longitude) developed by Jack Dan Hollister and Dr Ben Price.

It is particularly useful for digitisation and georeferencing workflows, allowing curators to process large numbers of historical specimen records efficiently.

## [TCS](https://bioresearch.byu.edu/tcs/)

TCS is a Java program for estimating gene genealogies from sequence data, producing haplotype networks that can incorporate multifurcations and reticulations where a strictly bifurcating tree is not appropriate. Developed by the Brigham Young University Computer Science Department.

Particularly useful for population genetics and phylogeography studies where sequences are too similar to resolve into a fully bifurcating tree, such as intraspecific analyses or recently diverged lineages.

## [FigTree](https://tree.bio.ed.ac.uk/software/figtree)

FigTree is designed as a graphical viewer of phylogenetic trees and as a program for producing publication-ready figures. Developed by Andrew Rambaut from University of Edinburgh.
